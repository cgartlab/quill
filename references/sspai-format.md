# 少数派首页写作格式规范

> 本文件在编辑面向少数派（sspai）首页发布的正文时加载。
> 依据：少数派创作手册·风格指南（https://manual.sspai.com/rules/manual-of-style/）+ 作者实际投稿实践。
> 这里只收编辑正文时最常踩的硬规则；完整规范见官方手册。

## frontmatter（作者实践）

面向少数派的文章 frontmatter 加：

- `client: [sspai, C]`
- `platform: [sspai.com]`
- `toc: true`（少数派编辑器会生成目录）
- `abbrlink`：少数派文章固定链接缩写
- `cover`：题图路径
- `draft: true` / `published`：发布状态
- `lang: zh`

## 文首起手（作者实践）

- 一张题图（或 hero 图），后接一句加粗的活动/背景说明（如「本文参加 XX 征文活动」）。
- 若正文用了 AI 辅助（结构讨论、语言优化、资料整理），文首以 callout 披露：

> [!NOTE] AI 辅助创作披露
> 本文基于作者真实经历独立完成，后期使用 XX 进行结构讨论、语言优化和部分资料整理。会话链接：[链接]

- 以 `## 写在前面` 起手，交代动机与读者需先了解的背景。

## 中英文排版（最易踩）

- 汉字与英文字母、数字间手动加一个半角空格；英文紧邻中文标点时不加空格。
- 中文引用用直角引号 `「」`，内层用 `『』`；英文用弯双引号 `“”`，内层 `‘’`，不用直引号。
- 中文说明 / 列举 / 中断用两个长连接号 `——`；省略号用 `……`（两个 U+2026），不用句号代替。
- 中译人名间隔用 `•`，不用 `·` 或 `●`。

## 文本样式

- 标题层级连续，不跳级；不为例行放大字体而用标题。
- 粗体克制，不连续大面积；不代替标题；句末点号不入粗体（整句粗体除外）。
- 中文永不设斜体；英文书名用斜体（不用中文书名号），英文文章标题用正体 + 中文引号「」。
- 段落长短适中、自成一体；不用只有一句话的段落。
- 块引用内引文不加引号；不为强调 / 装饰而用块引用。
- 行内代码用于：终端命令、包名、文件名 / 路径 / 扩展名、URL / IP / 端口 / HTTP 状态码、代码语境下的属性 / 元素 / 类；不用行内代码表强调。

## 链接

- 链接文本要说明被链资源内容；不以「点击 / 下载 / 阅读」「这里 / 这篇」或裸 URL 做链接文本。
- 链接文本结尾的点号、两端引号不入链接（整句除外）；链接文本与前后文不额外加空格。
- 去除重定向短链、广告追踪参数（`utm_` / `fb_` / `ga_` 开头）；临时 / 易失效链接改用固定链接 + Internet Archive 归档，标注「原始内容存档于 [日期]」。
- 需登录 / 付费的标「需登录 / 需付费 / 付费墙」；失效链接补归档版并标注存档日期。

## 描述界面

- 省略元素类型名，直接用文本标签（「选择『声音』」而非「点击『声音』按钮」）。
- 跨平台用「选择」代替「点击 / 单击 / 轻点」；连续操作用 `>` 或 `–` 连接（「第一步」>「第二步」）。
- 按键首字母大写（sentence case），省略「键」字；组合键用 `+`（Windows/Linux）或 `-`（macOS）连接，前后一致；不用 Ctl/Opt/Cmd 缩写。
- 终端命令开头不加提示符 `$` 或 `>`。

## 日期 / 单位 / 货币

- 日期用汉字「yyyy 年 M 月 d 日 h 时 m 分 s 秒」，不前置零，不用横线 / 冒号 / 英文；国外事件注明「当地时间」或换算国内时间。
- 单位用国际单位制；数字与单位字母符号间加半角空格。
- 货币用「数值 中文单位名」：✓ 100 美元；✗ $100、USD 100、100 刀；外币后注「（合人民币 X 元）」。

## 图片（作者实践 + 官方）

- 有节制、图文对应；用他人图片标版权来源。
- 图片宽度用少数派编辑器语法控制：`![描述|620](file.webp)`，`|` 后为像素宽度。
- 纵向像素多于横向的图：裁剪 / 拼图 / 缩放，控制纵向占用。
- 编辑器单图限 2 MB；过大用 TinyPNG / PP 鸭 / ImageMagick 压缩。
- 遮挡敏感信息用纯色色块，不用马赛克 / 模糊 / 表情符号；每图宜填题注，题注不含正文未提的信息。
- 少用动图（GIF），仅静态图不足以传达时用。
- 题图：普通样式 1420×708（关键内容居中 708×708）；醒目样式 708×708（居中 615×615）。

## 引用

- 优先一手来源；避免长篇引用，引关键部分 + 概述 + 全文链接。
- 标注来源：脚注 `[^N]` / 括号夹注 / 上下文说明 + 链接。
- 引用受版权多媒体标权利人 / 作品名称 / 授权事实。

## 代码块

- 命令 / 脚本 / 配置 / 终端输出用代码块；选正确高亮语言。
- 含必要注释，注释置于被注释片段前，克制精简；执行结果另放一个代码块。
- 长代码删减突出重点，完整内容用外链；不用图片展示代码。

## 科技名词（节选，完整见官方附录）

- app（小写，不用 App/APP）；Apple（不用水果 / 苹果标志）；GitHub（H 大写）；Google / 谷歌；NVIDIA（全大写）；Sony / 索尼；Android / 安卓。
- 不用「按摩店」「巨硬」「大法」「老任」「亚麻」等戏称。

## 参考与工具

- 官方风格指南：https://manual.sspai.com/rules/manual-of-style/
- 中英文自动加空格：AutoCorrect、pangu.js。
- 死链 / 链接清理：ClearURLs、URL Clean、Internet Archive。
- 图片压缩：TinyPNG、PP 鸭、ImageMagick。
- 国标：GB/T 15834—2011《标点符号用法》、GB/T 7714-2005《文后参考文献著录规则》。
