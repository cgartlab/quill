# 风格规则与禁用清单

> 本文件在**校订期**加载（第九步验证与六遍改稿）。**起草期不必读它**——见 SKILL.md 第七步「起草期许可」：初稿阶段只守"不编造"一条底线，形式问题全部留到这里统一处理。
>
> **为什么后置**：起草期读着 20 条禁令写字，稿子会没有毛边、人也写不下去。禁令是校订期的工具，不是起草期的枷锁。

## 适用范围（先看这一条）

下面的形式级禁令（标点、句式、借喻、黑话）覆盖**成稿**——标题、小标题、正文、图片说明与引用转述。

Agent 的**结构化工作文件**（`claim` / `evidence` / `audience` / `style` / `_index` / `ai-draft` 的字段、清单标签、链接表）**不受标点禁令约束**，但其中的**成段议论与起草片段**仍按成稿标准写——那些文字会被搬进正文。

## 分两档（破折号与提示性冒号按作者基线，另见其条目）

- **A 档 · 单次即改**——正常中文里不会自然出现，出现即处理：
  不编造来源、铺垫过渡、空洞总结、复述式收尾、抽象权威话术、空泛情绪词、过度包装标题、AI 占位文本、翻案腔、抽象抒情、"说白了 / 先说结论"、模型洞察路标、商业黑话、模型鼓点收尾。
- **B 档 · 成簇才改**——正常写作也会用，**同段两处以上或全篇密度过线才动**：
  名词化、借喻包装、抒情词给抽象概念穿衣服。三项以上同构排比本身就是按"三项"触发。

> 分档的意义是**别过度执行**：把 A 档按 B 档的宽容度去改，或者把 B 档按 A 档的强度去追，都会把稿子改硬。

## 数量型规则按作者基线

标点与词汇的"多不多"，先取作者旧稿 3–5 篇量出密度，把实测值当上限，**不从零起算**。作者本就在写的东西，按他的密度写；作者不写的，才按清零处理。取不到语料时退回默认基线（即 AI 味）。

**实测基线表与判读要点见 `writing-craft.md`「标点与词汇密度基线」**（含 25 篇成稿的复测数据）。本文件不重复那张表——两处定义同一组数字必然漂移。

## 禁用清单

> **改法只有一条**：先找回这句**原本想说的事实**，再用普通句子说出来。**不要去找另一个"漂亮句式"替换**——那只会换上更工整的套话，把僵硬加重一遍。找不回事实就删，不要补一个没依据的说法。

### A 档条目（单次即改）

- **不写铺垫、过渡、空洞总结、复述式收尾**（"值得注意的是 / 不难看出 / 综上所述 / 总而言之 / 这说明了…的重要性 / 在某种程度上 / 或多或少"等一律不写）。**「换句话说」用于真承接作者的意思时放行**（如"换句话说，长期价值就是坚持做正确的事"——作者 25 篇成稿里用了 3 次，是正当用法），只禁拿来给段落抬价的。
- 不用"本质上 / 毫无疑问 / 显然 / 众所周知 / 不言而喻"堆砌抽象或权威话术。**单次本义用法放行**（如"它本质上是一种强溶剂"），只禁堆砌。
- 不用空泛情绪词（"震撼 / 颠覆 / 史诗级 / 无与伦比 / 颠覆性 / 史无前例"）替代证据。**描述真实感受时保留**（如"在 50 寸超宽屏上动起来还是非常震撼的"）。
- 不用过度包装标题（不加感叹号、不加"震惊 / 必看"、不用纯悬念式；中文标题不超 20 字）。
- 不写"根据知识库中的相关笔记…"等 AI 占位文本；不写没有具体场景的 AI 式总结开头。（这是假话，与 `［请作者补：…］` 缺口标记不同——后者是诚实的缺口，但校订期必须消解。）
- **禁翻案腔**：先立一个读者并没有的误解、再推翻它抬价——包括"不是A而是B / 并非A而是B / 不在于A而在于B / 与其说A不如说B / 表面上A实际上B / 看似A实则B / 你以为A其实B / 回头才发现 / A不重要重要的是B / 答案恰恰相反"及其一切变形。判断从正面下，先给判断再给依据。
- **禁抽象抒情**："时间保管细节 / 焦虑显形 / 岁月磨平"——给抽象概念配具体动词的句子一律还原为人做了什么、发生了什么。
- **禁"说白了 / 说穿了 / 先说结论"**。
- **禁模型洞察路标**："更微妙的是 / 还有一层 / 只说对了一半 / 值得注意的是 / 需要指出的是 / 从某种意义上说"不用于给段落抬价。文字确实在说楼层、数量、本义时保留。
- **禁商业黑话抬价**："赋能 / 抓手 / 商业闭环 / 价值闭环 / 能力沉淀 / 拉通 / 底层逻辑 / 顶层设计 / 认知跃迁 / 价值释放 / 能力建设 / 降本增效 / 内容矩阵 / 全链路 / 组合拳 / 打开想象空间 / 结构性机会 / 关键命题 / 深层逻辑 / 技术底座 / 公共底座 / 技术主权 / 单点风险 / 主脊柱 / 材料锚点 / 认知增量 / 迭代闭环"。改成人、动作、钱、时间与后果。**「底层逻辑」在本义指"规则/机制的核心设计"时放行**（作者 25 篇成稿里用了 3 次，如"文档中蕴含的底层逻辑"），只禁用它包装抽象价值。
- **禁模型路标式排比收尾**：每段都用一句短判断收尾 = 模型鼓点，删到只留最有材料的一处。

### B 档条目（成簇才改）

- **禁名词化**："进行了优化 → 改顺了"、"实现了增长 → 多挣了多少"、"完成了对流程的调整 → 把流程调好了"。看到"进行/实现/完成/开展"带动名词就还原成直接动作。**B 档，同段两处以上或密度超作者基线（实测 0.06/千字）才动**——作者会用（25 篇 4 处），不是从零清零。
- **禁借喻包装**："仓库 / 抽屉 / 温度 / 死亡 / 坍塌 / 浪潮 / 钥匙 / 底座"不用于包装抽象概念。**文章真在写这些东西时不受影响**（实测：作者写 GitHub / NAS 时"仓库""钥匙"全是字面用法）。
- **禁抒情词给抽象概念穿衣服**："安放 / 抵达 / 微光 / 褶皱 / 丰盈 / 滚烫 / 轻盈 / 赤裸 / 剥开"——**写具体事物时保留**，给抽象概念提气时删掉。
- **禁三项以上同构排比**：同一句型连排三次以上留两项，第三项换说法或删掉。

### 按作者基线判（不按绝对数）

- **禁破折号（过量）**：按作者基线判，超量即减；取不到语料时清零。标题、引文原文、来源分隔符原样保留，不属改写范围。
- **禁提示性冒号（抬价式）**：只禁抬价用法——"一句话总结：" "核心是：" "关键：" 一律改写。引出人物直接原话、以及结构性标签（"标题：说明""版本号：变更"）按作者基线放行。网址、代码、机器字段除外。
