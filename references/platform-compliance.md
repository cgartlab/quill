# 发布平台合规参考

> 本文件在**第六步之后（平台勾选定下）加载**，作为**写作过程中的合规扫描**；第九步校订期做**最后一道闸门**复核。
> 与 `references/style-and-bans.md` 并列但维度不同：`style-and-bans.md` 管**形式禁令**（翻案腔 / 名词化 / 商业黑话 / AI 味），本文件管**平台审核**（能不能发、发出去会不会被限流 / 屏蔽）。
> 起草期（第七步）不加载——起草期只守"不编造"（见 SKILL.md 第七步「起草期许可」）。
> 本文件不堆平台细节，抽**跨平台共识**：低创作度、导流、AI 披露。各平台审核口径会变，判定原则比具体条目持久——具体条目以当时最新公告为准。

**三平台共识来源**：
- **微信**：「低创作度案例解析」「导流案例解析」（2025-10）
- **小红书**：社区公约 3.2（导流零容忍）、3.1.4（虚假营销）、AI 内容需标注
- **知乎**：AI 辅助创作公告（2026）、社区规范（抄袭 / 恶意营销导流）
- **少数派**：见 `references/sspai-format.md`（AI 披露 callout、利益相关声明）

**触发时机**：用户在第六步勾选发布平台后立即加载本文件扫描当前草稿；写作过程中若发现踩线，**在当下改**，比校订期再返工便宜得多。校订期第九步再复核一遍，作最终闸门。

## 适用与豁免

- **在稿件指向任一已覆盖平台时生效**（`client:` frontmatter 含 `wechat / xhs / zhihu / sspai`，或作者明确说要发到某平台）
- **不发这些平台的稿件豁免本文件**（只看 style-and-bans）
- **Agent 自己写的 `ai-draft.md` 是用户草稿的一部分**——扫描时把 Agent 的产物和用户的稿子一视同仁，用户决定采纳哪一段。Agent 不用自己给"我这段是不是 AIGC"打标，但**不能把整段 AI 生成的文字不改动地塞进 `ai-draft.md`**（等于把低创作度原文照搬的责任从用户转嫁给 Agent）。最低增量：AI 生成段落采纳前，作者要**改结构 + 补自己的判断**，不能只改措辞。

## 六项扫描

扫描时按下面六项过一遍草稿，逐项给结论。每项都要能指认到具体位置或具体信号——给不出就当作未扫描。

### 一、标题与小标题（4 项红线可能都藏在这）

**扫什么**：标题、所有 `##` / `###` 小标题、首段前 3 行。

**红线信号**：
- **标题党**：绝对化用语（"最 / 唯一 / 100% / 根治"）、情绪煽动词（"震惊 / 必看 / 后悔没早知道"）、图文不符
- **敏感品类**：医美、医疗器械、金融、保健品——高判罚风险，无资质不发
- **导流话术**：标题里塞"扫码 / 加群 / 完整视频见"等
- **AI 味标题**：模型路标式（"更微妙的是 / 只说对了一半"）、抽象抒情、煽动式金句

### 二、正文原文与段落（低创作度三条 + 引文归属）

**扫什么**：全文每一段（尤其连续 3 段以上无插话的段落）。

**红线判据（同时满足才命中，任一不满足都不算）**：
- **直接搬运站外内容**：连续 **≥ 200 字** 与单一外部来源高度重合（≥ 80%），**且**无自己的观点或补充表达
- **AIGC 文字原文照搬**：AI 生成的**逻辑结构与措辞均未改**（改两三个词但保留原文论证结构 = 仍属命中）
- **图表原样搬**：**从站外**搬的图表未重绘 / 未重述——自制图不受影响

**引文归属**：每处引用他人观点，首次出现要说明是谁说的。全部靠公开材料撑论点时，开头附近留一处检索痕迹（一句"参考了 X / Y"）。

### 三、图片（AI 配图 + 素材来源）

**扫什么**：每张正文图片（含题图）、图片标题、图片说明。

**红线判据（三条件同时满足才命中"AI 图片为主体"）**：
- AI 生成图**是主体素材**（首图 / 占正文图片 ≥ 50% / 主题封面）
- 存在**明显不合理之处**（手指畸形 / 文字扭曲 / 光影矛盾）
- **无作者观点评述**——正文没有围绕这张图展开判断、评论、延伸

**豁免三条件（同时满足即豁免）**：
- **披露**：图片来源 / AI 生成 / 版权标注清晰（文首 callout、图片标题、或文末注释任一处）
- **有增量**：正文围绕图片有原创观点（评价方法论 / 适用性 / 自己的判断）
- **非主体**：不是首图 / 不是全文唯一素材

**白名单**（明确不是"AI 生成"）：作者实拍、系统截图、品牌 logo、CC0 公开素材、明确标注来源的第三方素材。

### 四、外链与二维码（引用 vs 导流的边界）

**扫什么**：全文所有链接、图片 alt、文中提到的二维码 / 群聊 / 小程序。

**引用来源类链接（不属导流）**：
- 官方文档、维基百科词条、原始文章 / 采访原文
- 作者自己的 GitHub 代码仓库、工具官网（工具教程里的必要资源指引）
- 作者自己的其他公开内容（读者自主跳转，无交易 / 骚扰链路）

**跳转引导类链接（属导流红线）**：
- 二维码图片、短链（t.cn / d.cn / douc / bililink）
- 小程序跳转按钮、"戳这里 / 点这里 / 扫码领" CTA 话术
- 引导到群聊、公众号、其他公众号、第三方商城 / 直播间

**判断口径**：链接是**为了让人能查到来源**，还是**为了让人跳转去做动作**（关注 / 加群 / 下单 / 私信）。前者放行，后者算导流。

### 五、正文里的导流话术（关键词表）

**扫什么**：正文每一个段落（尤其文末 200 字）。

**关键词表**（命中任一即视为命中，需要作者判断是引用还是引导）：
- **互动导流**：`加V / 加 v / 加微 / 加我微信 / vx / wx / weixin / 私我 / 私信我 / 扫码 / 加群 / 评论区扣 1`
- **内容导流**：`完整版见 / 全文见 / 戳这里 / 点这里 / 扫码领 / 跳转 / 小程序 / 详细版见`
- **多重嵌套**：`加助理 / 加小助手 / 加客服 / 加我助理 / 助理会拉你进群`

**注意**：命中关键词不代表一定违规——引用别人写过的话、介绍某功能、讨论某产品的官方术语都可能带这些词。Agent 报出命中位置，由作者判断。

### 六、AI 使用披露（跨平台一致要求）

**扫什么**：文首、文末、frontmatter 的 `ai-assisted` 字段。

**各平台要求**：
- **少数派**：**强制**。文首用 `> [!NOTE] AI 辅助创作披露` callout，写明工具 / 用途 / 会话链接（见 `references/sspai-format.md`）
- **小红书**：**强制**。AI 生成图 / 视频需声明为 AI 生成
- **知乎**：**要求显著标识**。依《人工智能生成合成内容标识办法》——AI 生成内容需在醒目位置标识
- **微信**：**未强制**，但披露后降低误判风险

**推荐范式**（跨平台通吃，一次披露到处能用）：
> 本文基于作者真实经历独立完成，后期使用 [工具名] 进行结构讨论 / 语言优化 / 部分资料整理。会话链接：[链接]

**兜底原则**：**未披露 + 无明显 AI 味 + 有原创表达 = 默认视为原创**。规则不变成"只要没披露就有风险"——那会让所有稿子都得披露才敢发。

## 五类边界（Task 分析出的高频模糊区）

以下是写作中最常踩到的模糊区，逐条说清怎么判。

**1. 引用性截图 vs 搬运截图**：教程文章里贴官方文档截图 + 有明确评论 / 讲解 = **引用性截图，放行**；截图当唯一论据 + 无评论 = 搬运，命中。判据是**作者有没有围绕截图说话**。

**2. 自制图表 vs 站外表图**：作者自己画的 mermaid 流程图 / 数据图 = **自制，放行**；从别处搬的图表未重绘 = 命中。图表标题或文末注释里说清"自制 / 重绘 / 来源"最有效。

**3. AI 生成图 + 主动披露 + 有观点**：三条件同时满足（披露 + 有增量评述 + 非主体位置）= **豁免命中**。**反面案例**：AI 生成一张插画放在开头当题图，正文没围绕它展开 = 命中"AI 图片为主体"。**正面案例**：AI 画一张封面，正文引用它作为讨论对象并给出自己的判断 = 豁免。

**4. 引用来源链接 vs 跳转引导链接**：文末列 30 个官方文档 / 维基词条 / 作者 GitHub = **引用来源，放行**；文末塞"扫码进群 / 加助理领完整清单" = 命中。**判断口径是"读者点链接是为了查东西，还是去做动作"**。

**5. 好物推荐与工具盘点（疑似带货）**：**这是老板写作形态里最容易踩的类型**，也是规则最容易判错的地方。判定原则：
- **纯评价 + 无外链 / 仅指向官方文档** = **原创推荐，放行**（"我用了三个月觉得好用"）
- **评价 + 外链到第三方商城 / 直播间 / 群** = **导流，命中**
- **含"神器 / 值得入手 / 必买 / 亲测推荐"等营销话术** = **边界模糊，建议披露利益相关**（如果拿过推广分成 / 品牌合作，必须在文首声明）

## 账号侧自查（Agent 看不到，作者自查）

以下三处**Agent 校订期够不着**（那是账号配置，不是草稿内容），本文件明确写"由用户自查"，不列进扫描清单：

- **账号简介**：不塞微信号 / 二维码 / 外链（互动导流零容忍）
- **自动回复模板**：关注后自动发的消息不带联系方式 / 外链
- **评论区话术**：作者自己不要在评论里塞微信号 / 二维码

## 和 `style-and-bans.md` 的分工

- `style-and-bans.md`：形式禁令，**改文字本身**（删翻案腔、去黑话、消解抽象抒情）
- 本文件：发布合规，**判断能不能发**（搬运 / AIGC 原文 / 图片主体 / 导流 / 嵌套跳转 / AI 披露）
- **两份都清零才算校订期完成**——命中本文件的红线**不能用"文风就是这样"来豁免**，平台审核不看作者意图
