# 写作质量的第一性原理拆解与研发方向

调研与测量时间 2026-10-03。这份文档回答一个问题：**quill 要提升写作质量，下一刀该切在哪。**

它不是功能清单，是从"agent 辅助写作到底在发生什么"倒推出来的。所有数字都是本仓库实测。

---

## 一、结论先行

**quill 的规则质量分布是倒的。** 实测（字符数）：

| 层 | 风格 / 禁令 / 改稿 | 材料 / 证据 |
|---|---|---|
| **常驻层**（SKILL.md，每次激活全量加载） | 风格与禁用 2646 + 第九步验证 1045 + 冲突优先级 329 ≈ **4020** | 材料清点 354 + 第四步证据 694 ≈ **1048** |
| **按需层**（writing-craft.md） | 多遍改稿 1601 + 可量化自检 1538 + 起草规则 898 + 密度基线 893 + 声音校准 503 + 结构接缝 392 + 正向清单 567 ≈ **6392** | 只有「没有亲历时的范围纪律」301 |

**常驻层里风格类规则是材料类的 3.8 倍；单看「风格与禁用」一节，是「材料清点」的 7.5 倍。**

而那条最要命的诊断——`具体指称密度低`，判据写着「材料稀薄是整篇的底色。补材料，不是补形容词」——是 13 行表格里的第 4 行，藏在只在第七步加载的参考文件里。

## 二、拆解：agent 辅助写作的本质

把输出质量写成上界：

```
Q = min( 能力上限 , 信息上限 )
```

- **能力上限**：模型把中文写好的一般能力。**很高**——前沿模型写得好。
- **信息上限**：模型对**这一篇**知道多少——这篇的事实、这位作者的亲历、他的声音、他的读者。

**模型失败的方式不是能力不够，是它会一路写到信息上限然后继续写下去**，用抽象、概括、漂亮句子把空的地方填满。它不会停下来告诉你"这一段我手里没东西"。

这一条直接解释禁用清单上的**每一个**条目：

| 禁用项 | 真实成因 |
|---|---|
| 名词化（"进行了优化"） | 不知道谁做了什么 |
| 抽象抒情 | 手里没有具体画面 |
| 空洞总结 | 没有结论可下 |
| 复述式收尾 | 没有新东西可加，只能重说一遍 |
| 洞察路标（"本质上/归根结底"） | 标注一个并不存在的深度 |
| 借喻包装 | 没有事实，只有意象 |
| 空转句引列表 | 引导句不承载信息，只能指向清单 |

**大部分禁用词不是文风问题，是材料贫乏的症状。删掉它们是在治标。**

不是说不该有清单——用户确实给不出更多材料时，抑制症状能逼出"要么找材料、要么删掉这句"；而 0.3.0 加的改法规定（"先找回这句原本想说的事实，再用普通句子说出来"）已经写对了机制。但它排在第二顺位，却在第一顺位占着 2646 字符。

## 三、quill 内部有两套理论，被焊在一起

**理论 1**（`framework.md` / 核心理念）：「长文写作的核心困难不是'不知道写什么'，而是'知道很多但理不清'」→ 人脑工作记忆小 → 把 claim/evidence/audience/style 卸载到四个文件。

**理论 2**（SKILL.md 禁用清单）：模型有默认的坏腔调 → 逐条禁掉。

两套都没错，**但它们回答的是两个不同人的问题**：

- 理论 1 讲的是**人类作者**的困难（材料过剩、理不清）
- 理论 2 讲的是**模型**的困难（有腔调、没材料）

**材料本身——人和 agent 差异最大的那一轴——恰好掉在两者中间，没人管。** 理论 1 假设材料过剩，理论 2 假装材料无关。

后果：材料清点被做成一道**一次性闸门**（第一步半），出现在用户还没试着写的时候；材料出处的检验被埋在**第二遍改稿**里，是六遍中的一遍。`五件材料`因此很容易被乐观计数蒙过去——它是**纸面可满足的**。

## 四、四个设计问题（按价值排序）

### 问题 1（价值最大）：材料核查在错误的时序上

现在：材料清点（写之前一次）→ 写 → 六遍改稿（事后清理）。
正确：**每段都知道自己是用什么做的。**

quill 已有这个原语，`writing-craft.md` 第二遍改稿里：

> 给每段标一个不公开的材料出处（用户材料 / 公开来源 / 可核验流程）。只能写出"这是进一步解释"或"这是可能的影响"，说明这一段没有新东西。

**它应该从"改稿的一个动作"提升为"起草时的一条约束"**：写这一段之前先知道它由什么构成；说不出来就不要写这一段——去找材料，或者删掉。

注意这是**减规则**：一条替代掉一大批禁令的事后追捕。

> **风险（必须先小样本对照再改）**：让模型"写之前先确认材料"可能让它变得畏手畏脚。0.4.0 的时序保护（"起草期不边写边自查"）正是为解决一模一样的坑而加的。**不做对照实验不要直接改 SKILL.md。**

### 问题 2：风格规则应该是校准的，不是绝对的

quill 已经发现这件事（0.3.0）：禁破折号与作者实测密度（1.83/千字）硬冲突，修法是「按作者基线」。

**但修法只覆盖 3 项**（破折号 / 冒号 / 连词）。清单上其余十几项仍是绝对禁令。

第一性原理：**清单上每一条都是关于这位作者的经验主张，而每个经验主张都可以测。**

已测过：翻案腔（10 篇 1 处）、名词化（10 篇 1 处）→ 维持全禁**零风险**，作者本来就不写。
**从没测过**：借喻包装（仓库/抽屉/温度/死亡/坍塌/浪潮/钥匙/底座）、抒情词（安放/抵达/微光/褶皱/丰盈/滚烫/轻盈/赤裸/剥开）、三项以上同构排比、模型洞察路标、金句密度。

这些恰好是**"会削掉作者写法"而不是"防模型腔"的那一类**，而 0.3.0 的教训正是：削掉作者写法 = 把稿子改硬。

判据是机械的，两种结果都有用：
- 语料里出现 ≈ 0 → 禁令安全，保留
- 语料里出现 > 0 → **这条禁令正在删除作者的声音**，必须改成密度规则

**这是真值，不是裁判意见。**

> **当前阻塞**：需要**已发表成稿**的干净语料。`cgartlab-obsidian`（704 个 md）不能直接用——它混着作者自己的写作与剪藏参考资料（《黑客帝国》解析、宫崎骏/诺兰/乔布斯人物笔记）。整库测量量的是**作者读了什么**，不是**作者怎么写**。需要先确定成稿清单（cgartlab.com 已发布文章，或 vault 里可确认的成稿目录）。

### 问题 3：反驳的位置和它的目的不匹配

`writing-craft.md` 明说：写作自检是"向内找问题"，反驳是"向外找反证"，两者都在稿子写完**之后**。

但模型在写作里最有价值的用途不是事后批评，是**在你把论点写死之前先把论点打一遍**。

现在：第三步定论点 → 第七步写全文 → 第八步反驳。**等反驳发生，整篇已经建在这个论点上了**，反驳结果最多让你补个边界。

应该**拆成两次**：第三步后做一次便宜的证伪检查（这个论点可反驳吗？最强反方是什么？），第八步做完整的。与问题 1 同向——**把力气从清理挪到预防**。

### 问题 4：「五件材料」把结果当成了原因

`五件`与 `3-5 条支撑要点`、`一个要点不超过 1 段` 同体系，粗算自洽（3-5 要点各一件 + 开头场景 1-2 件）。

但真实不变量是**每段都有材料出处**，五件只是它在 2000 字篇幅下的推论。**篇幅 5000 字时五件显然不够。** 门槛应随篇幅走。

---

## 五、建议的推进顺序

1. **先做问题 2 的测量**（不改变任何流程、不碰时序风险，只是拿真语料核一遍已有规则）。前置：确定成稿清单。
2. **问题 1 做小样本对照**，再决定是否改 SKILL.md。价值最大、风险也最大。
3. 问题 3、4 随 1 一起改（同一个方向：预防优先于清理）。

**该删的**：可量化自检 13 行里，有 5 行（具体指称密度低、借喻聚集、金句过密、洞察路标超量、空转句引列表）是材料贫乏的下游症状——问题 1 做对了它们自动消失。剩下 8 行是真正的句法检查（相邻句结构同款、重定语句、段落可交换等），**留下**。

## 六、与「经历与事件」硬规则的关系

0.5.0 加的「经历与事件必须可指认来源」属于**信息上限**这一轴——它拦住的是"用编造的现场把信息缺口填满"，正是本文第二节说的那个失败机制的最危险形态。

**它和问题 1 是同一件事的两端**：硬规则管"不许编"，材料会计管"手里到底有什么"。**只有禁令没有会计，模型会被逼到没东西可写；只有会计没有禁令，模型会拿编造的东西填账。两者必须成对。**
