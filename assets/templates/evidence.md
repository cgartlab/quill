## 经历与事件来源（硬规则）

> 正文里每一处"谁在什么时候做了什么、发生了什么"都要在这里指认来源。
> **准入标准只有一条：能找到真实的正确链接。** 指认不出 → 删掉、换写法、或标 `［请作者补：…］`，不许留在正文。
> 两类三小类：**①你公开写过的 / ②从你公开内容推理可得的**（链接落到你那篇原文）· **③客观事实与别人公开写过的** · **无链接**（不许进正文）。
> **Agent 自己的凭空推断不是来源**——组织材料是写作，发明现场是造假。
> **链接在 = 材料合格；合不合适放进文章，由用户最后判断**——本表只摆事实供用户定，Agent 不替用户判取舍。

| 编号 | 来源 | 身份 | 独立性 | 内容摘要 | 可信度 | 链接 | 访问日期 |
|------|------|------|--------|---------|--------|------|---------|
| E1 | | ①–⑤ | 独立/同源/转载/不明 | | 高/中/低 | | |
| E2 | | | | | | | |

> **身份**决定它怎么被写进正文（第 ②③ 类第一次出现要说清是谁的说法）；**可信度**决定它能不能进关键支撑链；**独立性**说明它是不是另一条路的重复——三篇同源通稿不构成三个独立佐证，按证据**起源**算，不按链接**条数**算。
