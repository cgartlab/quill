# 风格与修辞

## 纲领

> 结构为骨，自由为魂，真诚为血，高信噪比为气。

风格 = 长期偏好被约束后的结果，不是语气、不是漂亮句子、不是模板。

## 声音（稳定偏好）

- 短句优先（一段超五行考虑拆开）
- 主动语态
- 具体例子优于抽象概括
- 少空泛形容词与情绪词
- 保留第一人称判断（「我认为 / 我不同意 / 我踩过这个坑」）

## 禁用清单（比鼓励清单更易守住）

### 内容级
- 不编造来源；不用「本质上 / 毫无疑问」堆砌抽象
- 不用空泛情绪词（「震撼 / 颠覆 / 史诗级」）替代证据
- 不用过度包装标题；不把 AI 猜测写成事实
- 不写没有具体场景的 AI 式总结开头
- 不留「根据知识库中的相关笔记…」等 AI 占位文本
- 不修改用户的草稿——只读不写

### 形式级
- **禁翻案腔**：「不是A而是B / 表面上A实际上B / 你以为A其实B」及一切变形
- **禁三项以上同构排比**：同一句型连排三次以上留两项
- **禁抽象抒情**：「时间保管细节 / 焦虑显形」→ 还原成人做了什么
- **禁名词化**：「进行了优化 → 改顺了」「实现了增长 → 多挣了多少」
- **禁破折号**：`—` / `——` / `–`
- **禁提示性冒号**：`：` / `:` 只允许引出直接原话
- **禁「说白了 / 说穿了 / 先说结论」**
- **禁模型洞察路标**：「更微妙的是 / 还有一层 / 值得注意的是」不用于抬价
- **禁商业黑话**：「赋能 / 抓手 / 闭环 / 底层逻辑」等 → 改成人、动作、钱、时间
- **禁借喻包装**：「仓库 / 抽屉 / 温度 / 死亡」不用于包装抽象概念
- **禁抒情词给抽象概念提气**：「安放 / 抵达 / 微光 / 褶皱」→ 写具体事物时保留，给抽象概念提气时删掉
